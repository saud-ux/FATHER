# مسابقة الخلايا — كل الملفات في جذر واحد

فك الضغط وارفع الملفات نفسها مباشرة على فرع `main`. لا ترفع مجلدًا خارجيًا يجمعها. كل ملفات المصدر في هذا الملف المضغوط موجودة في الجذر، دون أي مجلدات.

هذه نسخة مستقلة من أحدث اللعبة: واجهة مبسطة بلهجة عامية، لوحة ٥×٥ بصفوف تحت بعضها، وأسئلة وصور المرفقات. لا تُربط الأسئلة بالخلايا.

## الرفع على GitHub

1. أنشئ مستودعًا **Private** لأن الملفات فيها إجابات المسابقة وصور الأصدقاء.
2. فك ضغط ZIP وافتح المجلد الناتج.
3. من GitHub اختَر Add file ثم Upload files.
4. حدّد الملفات نفسها وارفعها مباشرة، ثم احفظها على `main`.
5. عند فتح الريبو يجب أن ترى `package.json` و`worker.ts` و`README.md` في الصفحة الأولى.

رفع الملفات إلى GitHub يحفظ المصدر فقط. لتعمل اللعبة والمزامنة بين الجوال واللابتوب، جهّز الاستضافة كما يلي. GitHub Pages وحده لا يشغّل خادم اللعبة أو حفظ الصور.

## تجهيز الاستضافة مرة واحدة — للمساعد التقني

يلزم Node.js 24 أو أحدث، وحساب Cloudflare بالخطة Workers Free، وقاعدة D1 مجانية. لا تحتاج R2 أو تفعيل فوترة أو شراء نطاق؛ استخدم رابط workers.dev المجاني. لا تستخدم Render لهذه الحزمة.

من جذر المشروع:

```sh
npm install
npx wrangler login
npx wrangler d1 create majlis-game
```

انسخ `database_id` الذي يعيده أمر إنشاء القاعدة وضعه بدل `00000000-0000-4000-8000-000000000000` في `wrangler.jsonc`. احتفظ باسم الربط `DB`. إذا غيرت اسم القاعدة فغيّره في الإعداد أيضًا.

أنشئ جدول الجلسات **مرة واحدة**، ثم انشر:

```sh
npm run db:remote
npm run deploy
```

افتح رابط Workers الذي يظهر بعد النشر. التحديثات اللاحقة تحتاج `npm run deploy`، دون إعادة إنشاء الجدول.

للتجربة المحلية، بدل أوامر النشر:

```sh
npm run db:local
npm run dev
```

لتشغيل الاختبارات:

```sh
npm test
```

أوامر التجهيز تولّد مجلدات `node_modules` و`dist` و`.wrangler` تلقائيًا. هذه مجلدات تشغيل وليست موجودة داخل ZIP ولا تحتاج ترفعها إلى GitHub. لا ترفع ملفات `.env` أو `.dev.vars` أو مفاتيح حسابك.

## المجانية وحدودها

Cloudflare Workers لا يستخدم سليب الخمول وانتظار التشغيل الموجود في Render Free. البيانات محفوظة في D1، وليست في ذاكرة العامل. هذا لا يعني ضمان تشغيل بلا أعطال.

الخطة المجانية حاليًا: ١٠٠ ألف طلب في اليوم، و٥ ملايين صف مقروء و١٠٠ ألف صف مكتوب في D1 يوميًا، وحد ٥٠٠ ميجابايت لقاعدتنا الواحدة. للطلب الواحد حد ١٠ مللي ثانية من وقت المعالج. تظل الخطة مجانية ما دمت على Workers Free؛ عند بلوغ الحد قد تتوقف الطلبات حتى تجدد الحصة، بدل الادعاء بأنها غير محدودة.

جهازان مفتوحان لمدة ٦ ساعات مع مزامنة كل ١٫٥ ثانية ينتجان حوالي ٢٨٬٨٠٠ طلب مزامنة، إضافة إلى الأوامر والصور. أغلق التبويبات بعد اللقاء، ولا تشارك رابط الاستضافة على نطاق واسع. حذف سؤال لا يسترد تلقائيًا مساحة صورته؛ راقب مساحة القاعدة من لوحة Cloudflare.

مصادر الحدود: https://developers.cloudflare.com/workers/platform/pricing/ وhttps://developers.cloudflare.com/d1/platform/limits/ وhttps://developers.cloudflare.com/d1/platform/pricing/ . لم تُختبر حصة المعالج المجانية على حساب منشور؛ إنشاء البنك لأول مرة أو الصور الكبيرة يحتاج تجربة فعلية بعد النشر. إذا ظهر خطأ، لا تعتبر الأمر محفوظًا قبل عودة حالة الاتصال والمزامنة.

## طريقة اللعب لأبوي

1. افتح اللعبة على اللابتوب. ترجع لنفس اللعبة تلقائيًا؛ عند التجهيز لأول مرة اضغط «افتح اللعبة».
2. انسخ «رابط اللعب والخلايا» وافتحه بالجوال للتحكم باللوحة واختيار وعرض الأسئلة. افتح «رابط الإعدادات» لإضافة الأسئلة وتعديلها وتغيير أسماء الفرق. الرابطان خاصان ومرتبطان بنفس الجلسة؛ خلّهما لك لحالك.
3. وصّل اللابتوب بالبروجكتر بوضع تكرار الشاشة. اضغط «ابدأ اللعب على اللابتوب»، وبعدها «كبّر الشاشة».
4. من الجوال افتح «الأسئلة»، اختَر سؤال واضغط «ورّهم السؤال».
5. تبي تعرض الحل؟ اضغط «ورّهم الجواب».
6. ارجع للوحة، اختَر خلية، واضغط «اعطها» للفريق اللي جاوب صح.
7. ما عرفوا الجواب؟ خلّ الخلية فاضية وخذ سؤال ثاني. غلطت؟ اضغط «تراجع».

الأزرق يصل اليمين باليسار، والأحمر يصل الأعلى بالأسفل. الأضلاع المتصلة هي اللي تنحسب، والفوز يظهر تلقائيًا. جولة جديدة تفضّي اللوحة وتصفّر الانتصارات وتحفظ الأسماء والأسئلة اللي سألناها. تغيير الأسماء والاتجاهات وإضافة الأسئلة من الإعدادات.

## الحفظ والخصوصية

الجهازان يحتاجان إنترنت. المزامنة كل ١٫٥ ثانية تقريبًا إضافة إلى زمن الشبكة. الجلسات والصور محفوظة بشكل دائم في D1، وتحديث الصفحة ما يصفّر اللعب. الأوامر المتعارضة لا تُنفذ فوق بعضها، والضغط المتكرر لا يحسب الفوز مرتين.

رابط الجمهور وحده ما يعطي التحكم أو بنك الإجابات. الإجابة لا تصل لشاشة الجمهور إلا بعد أمر صريح من المقدّم. الصور والإجابات مضمنة في `questions.ts` للخادم فقط، وليست ضمن ملفات المتصفح العامة.

**فرق الاستضافة:** هذه الحزمة المستقلة لا تحتوي بوابة تسجيل حساب ChatGPT التي تحمي الموقع الأصلي. صلاحية المقدّم هنا محمية بمفتاح رابط الجلسة. رابط الاستضافة يفتح اللعبة الواحدة للجمهور. بعد التجهيز الأول لا يستطيع الزائر إنشاء جلسة منفصلة أو الحصول على مفتاح المقدّم؛ احتفظ برابط اللعب والإعدادات الخاصين. إذا أردت تقييد دخول الموقع كله، جهّز Cloudflare Access على مستوى الاستضافة. لا تشارك رابط المقدّم.

لا توجد داخل الملفات بيانات الجلسات الفعلية أو روابط المقدّم السرية. بيانات الموقع المنشور حاليًا لا تنتقل تلقائيًا إلى الاستضافة الجديدة. صور وأسئلة المرفقات موجودة، أما التعديلات التي أجريتها داخل جلسة فعلية فتبقى على استضافتها الأصلية.

## المحتوى والاختبار

البنك ٦١ سؤالًا: ٥٩ جاهزة وسؤالان محجوبان للمراجعة، هما بداية سؤال اجتماع ينبع المقطوعة وإجابة سؤال الذهب غير الواضحة. إجابات الصور من تأكيد المستخدم، دون استنتاج أسماء من الوجوه، ولا اشتراط لحرف الإجابة.

فُحص بناء الواجهة و١٤ اختبارًا لمنطق اللعبة و٥١ اختبارًا للخادم مع مخزن الصور الجديد في قاعدة SQL. واختُبر مخزن الصور الجديد باستخدام SQLite: صورة بحجم ٨ ميجابايت، مطابقة البايتات، إغلاق القاعدة وإعادة فتحها، حفظ نوع الصورة واستبدالها بصورة أصغر. أُخذت الواجهة والمنطق من أحدث النسخة المنشورة. هذه الحزمة المستقلة لم تُنشر إلى حساب Cloudflare الخاص بك؛ يلزم تجربة الجوال والبروجكتر والاتصال بعد تجهيز الاستضافة.
